# Староста.ВК — Продакшн-проект для VK Mini Apps и Бота ВК

Все демонстрационные данные удалены. Приложение готово к публикации на хостинге ВКонтакте (`vk-miniapps-deploy`).

## 1. Публикация мини-приложения в ВКонтакте

1. Перейдите в панель разработчика ВК: https://dev.vk.com/ → **Мои приложения** → **Создать** → выберите тип **Мини-приложение**.
2. Скопируйте **ID приложения** из настроек и пропишите его в файле `vk-hosting-config.json` в поле `"app_id"`.
3. В терминале внутри распакованной папки выполните:
   ```bash
   npm install
   npm run deploy
   ```
4. Пройдите авторизацию в консоли `vk-miniapps-deploy` — сборка автоматически загрузится на хостинг ВКонтакте и станет доступна по адресу `https://vk.com/app<ВАШ_APP_ID>`.

## 2. Запуск сервера рассылки от имени бота ВК

1. В сообществе ВК вашей группы откройте **Управление → Работа с API → Ключи доступа** и создайте ключ с доступом к сообщениям сообщества.
2. Запустите сервер бота:
   ```bash
   VK_GROUP_TOKEN=ваш_ключ_сообщества PORT=3001 node bot_server/bot.js
   ```
